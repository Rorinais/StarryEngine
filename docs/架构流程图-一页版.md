# StarryEngine 架构一页图

## 1. 装配（main 只做连接）
```
AppConfig::load
   │
Application app(cfg) ── Window(GLFW) + VulkanRHI + 全局描述符池
   │
scene = make_shared<Scene>()
renderer = RasterRenderer(rhi, pool, scene)      // 自包含：全局布局/UBO/默认材质
SceneBuilder(scene, res).addSkybox().addGrid().addCamera().build()
   └─ (可选) ModelFactory::load(md, mset, mi) → scene->addObject(mi.geometry, mi.parts)
renderPath = RenderPathRegistry::create("deferred", rhi, w, h)
app.setRenderer(renderer, renderPath) → renderer->setRenderPath
app.setScene(scene)                   → path->setScene
app.initEventDispatcher()             → 相机控制绑定
app.run()
```

## 2. 每帧
```
run → step ─► rhi->renderFrame(λ encoder, imageIndex)
                  └► renderer->renderFrame
                        ├ buildSceneResources()      材质纹理/实例缓冲
                        ├ updateGlobals(slot)        全局 UBO(view/proj/lightVP/time)
                        ├ renderPath->render(imageIndex)
                        │    └ RenderGraph::execute → 每 pass executeDynamic
                        │         └ executor->execute()  ← 真正录命令
                        └ submitFrameDataJobs(nextSlot)  帧间解耦
```

## 3. 材质
```
普通:  MaterialDesc ─► MaterialFactory::create ─► DefaultMaterialTemplate + MaterialInstance ─► RHI
模型:  ModelDesc(资产) + MaterialSetDesc(策略: bindings/描边)
          └► ModelFactory::load ─► loadModel(ModelLoader→assimp→Geometry/Skeleton/Clip)
                                └► loadMaterials(SubmeshBinding→MaterialFactory + 模板写/描边/骨骼绑定)
```

## 4. 渲染路径
```
① 声明  StandardPipeline::declare(w,h)
          ├ RenderLayers::setPass(层 → pass 工厂)
          └ RenderTextures::define(name → TextureDesc)
② 定义  RenderPathRegistry::create("deferred"|"raytrace"|自定义)
③ 执行  DeferredRenderPath::buildDefaultPipeline()
          ├ 同步 RenderTextures → m_textureDescs
          └ RenderLayers::build(ctx = {w, h, setSlot(layer, pass)})
④ 建图  initialize → buildGraph
          ├ buildTextureIdMap     纹理节点(Swapchain 走 import)
          ├ buildConfigPasses     GraphicsPass::configure：按 (layer,queue) 建 subpass + 连附件
          ├ buildPresentationPasses  呈现链 / ImGui(UI,0)
          └ compileAndFinalize    编译 + PipelineCache 建管线
```

## 5. 分派（layer = pass，queue = subpass）
```
材质 setRenderLayer(N) / setRenderQueue(Q)
   └► DrawItem{renderLayer, renderQueue}
        └► key = (layer<<32)|queue
             ├► m_keyToSubpass[key]                       构建期校验
             └► GraphicsPass::onSceneData 按 key 匹配 → executor->addDrawItem(item)
未声明层 → 归入 (Opaque,0)；key 缺失 → LOG_ERROR
```

## 6. 管线 & 描述符集
```
SceneAnalyzer: GraphicsPipelineState 去重 → DrawItem.pipelineIndex / sceneData.PSO[]
GraphicsPass : PipelineCache::getOrCreate{stateHash, renderPass, subpassIndex, colorFmt, depthFmt}
Executor     : bindPipeline(mapping[idx]) → bindDescriptorSets → vkCmdDraw*

描述符集: set0 = 全局集, set≥1 = 材质私有
          每个 set 按 in-flight 帧槽复制 N 份(kMaxFramesInFlight=2)
索引空间: 帧槽 ≠ swapchain 图像索引（不可混用）
```

## 7. 扩展点
| 需求 | 接口 |
|---|---|
| 换层 pass | `RenderLayers::setPass(layer, factory, true)` |
| 新层 | `setUserLayer(8,"X")` + `setPass(8, factory)` |
| 新附件 | `RenderTextures::define(name, desc, true)` |
| 新路径 | `RenderPathRegistry::registerPath(name, factory, true)` |
| 材质层/队列 | `material->setRenderLayer/setRenderQueue` |
| 自定义绘制 | 实现 `IPassExecutor` + subpass `setExecutor` |
